## 一页结论
1. **系统病有突破，腺体仍是短板**：ianalumab（NEPTUNUS-1/2）、dazodalibep（OASIZ-301）、telitacicept Ⅲ期均达到 ESSDAI 主要终点，但唾液流率普遍无显著改善；ianalumab 仅在基线刺激流率 ≥0.4 mL/min 亚组的事后分析中见改善。
2. **残存腺体功能是关键分层因素**：TEARS 显示唇腺灶性指数高、超声分级高者对利妥昔单抗无应答；POETYK SjS-1 等新试验已把残存唾液流率写入入组标准。
3. **客观腺体终点**：唾液腺超声（OMERACT 0–3 分级 / 0–11 总分）与唇腺活检（灶性指数、浆细胞、Tfh）正在成为试验终点，但阅片一致性与活检取样可重复性仍需改进（图谱、多层切片、深度学习）。
4. **局部再生治疗是新方向**：MSC/外泌体颌下腺注射（NCT07838454，2026-12 拟启动）、HuMoSCs（NCT07861828）；AAV2-hAQP1 基因治疗在放射性口干已有阳性Ⅰ期数据，干燥症仍停留在动物实验。
5. **对症**：毛果芸香碱、西维美林证据最充分，适合仍有残存腺体功能者。
